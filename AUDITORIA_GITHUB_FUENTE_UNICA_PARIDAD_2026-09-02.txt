OBJETIVO
- Mantener apariencia, funciones e informes iguales entre PWA/GitHub, Windows Electron y Android.
- Evitar copias funcionales divergentes.
- No modificar la aplicación ni los machotes durante esta tarea.

CAMBIOS DE DISTRIBUCIÓN
1. Se creó config/runtime_distribution_manifest.json como contrato central del runtime.
2. scripts/distribution_parity.py copia/verifica el runtime por SHA-256.
3. scripts/build_web_release.py construye el artefacto PWA desde el runtime canónico.
4. Android sincroniza desde el mismo contrato central y verifica la copia antes de compilar.
5. Windows y Android verifican los archivos del artefacto final contra la fuente del mismo checkout.
6. Se agregó workflow GitHub Pages con CI, vendorización PDF offline, construcción y paridad.
7. Los workflows CI, Windows, Android y Release incluyen compuertas de fuente única/paridad.
