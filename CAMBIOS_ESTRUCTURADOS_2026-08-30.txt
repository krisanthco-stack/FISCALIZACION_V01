ETAPA 1 — GESTIÓN

ETAPA 2 — PDF Y LECTOR WEB
- Adjuntar/cargar PDF guarda el documento y lo analiza automáticamente.

- El número de trámite permanece protegido e inmutable.
- Si no hay texto digital, se intenta OCR automático local cuando el navegador/dispositivo ofrece TextDetector.
- El OCR automático se limita a páginas iniciales para proteger memoria/rendimiento en tablet.

- El visor PDF ya no muestra controles Leer página / Leer área.

ETAPA 3 — TERRITORIO
- Distrito: formato tipo oración (ej.: Las horquetas, Puerto viejo).
- Lugar/poblado: inicial de cada palabra en mayúscula (ej.: Las Palmitas).
- La agrupación ignora mayúsculas/minúsculas, acentos, espacios sobrantes y artículos iniciales El/La/Los/Las.
- Horquetas / Las Horquetas y HOQUETAS se reconocen como Las Horquetas para validación territorial.
- Palmitas / Las Palmitas y equivalentes se agrupan como el mismo lugar.
- Si un expediente tiene Lugar pero Distrito vacío, el Distrito se completa solo cuando todos los expedientes relacionados con ese lugar aportan un único Distrito válido.
- Si hay distritos contradictorios, no se infiere ninguno.
- Nunca se reemplaza un Distrito ya informado por esta inferencia.
