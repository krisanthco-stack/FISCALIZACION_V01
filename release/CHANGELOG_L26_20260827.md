# L-26 · Fiscalización V27.3.7-FINAL · 2026-08-27

## Liberación por etapas

### 1. Datos y enlaces
- Se conserva un único campo visible: **Enlace importado desde Excel / ID**.
- Si un expediente no posee enlace se asigna `https://metro.sarapiqui.go.cr/`.
- Un enlace real importado nunca es sustituido por el enlace predeterminado.
- El ID se conserva internamente para compatibilidad con importaciones anteriores.

### 2. Terreno
- La pregunta de cauce/cuerpo de agua conserva **No / Afectado** como respuesta principal.
- Expedientes antiguos con `Colinda con` se migran sin pérdida a **Afectado + Relación: Colinda**.
- Se mantiene la corrección previa de Uso Agro y Nivel de vía.

### 3. Croquis
- Mover un polígono conserva la nueva posición y no ejecuta auto-layout al volver a renderizar.
- Cada polígono se numera y enlaza con su nombre: `1-Casa`, `2-Cochera`, etc.
- El número se muestra dentro del polígono y el rótulo se ubica alternadamente en esquinas laterales.
- Se mantiene el cálculo interno de perímetro, pero se elimina su salida visual repetitiva.
- Se conservan ×2, ×1/2, rotación, mover/ubicar, vértices, escala común, cotas e historial.

### 4. Informe y Rectificación
- Se elimina la palabra **FIRMA** de la salida HTML/PDF y DOCX, conservando el espacio, la imagen y la línea de firma.
- Cada nueva Objeción recibe automáticamente un consecutivo `MS-FBI-RD-##-AÑO`.
- Para evitar colisiones, el cálculo del siguiente consecutivo reconoce también numeraciones históricas `MS-DFBI-RD-##-AÑO`.
- Los tres botones finales de Fiscalización se conservan y se compactan visualmente.

### 5. Gestión
- Aprobado: verde.
- Objetado: rojo.
- Para revisión campo: amarillo.
- Notificado: azul.
- Se elimina **Exportar paquete** de cada expediente y se incorpora **Notificando / Notificado**.
- Se conserva la exportación global `Exportar paquete Gestión` con expedientes, fotografías y documentos/PDF.
- Se mantiene la alerta de antigüedad de más de un año dentro de Gestión.
- **Trámites activos excluye todo expediente que ya pasó a Gestión.**

### 6. JSON / recuperación
- Cargar JSON en Trámites o Gestión **no reemplaza la base existente**.
- Los expedientes coincidentes se combinan/actualizan por ID o identidad inmueble–plano–derecho.
- Los expedientes nuevos se agregan.
- Los registros que ya existían y no vienen en el JSON permanecen intactos.
- No se ejecuta limpieza de IndexedDB durante la importación.

### 7. PWA
- Versión de aplicación: `27.3.7-FINAL`.
- Cache manual: `fiscalizacion-bi-l26-manual-20260827`.
- La instalación continúa disponible.
- La actualización continúa requiriendo la acción manual del usuario mediante el botón Actualizar.
